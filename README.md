# Follow Debbie

A small interactive story game built as a static web experience.

## Run locally

From the project root, start a local web server:

```bash
python3 -m http.server 8000
```

Then open:

- http://localhost:8000/
- http://localhost:8000/game.html

## Project files

- index.html: landing screen and menu
- game.html: main interactive story game
- game_story.html: alternate story prototype
- assets/: game art and video assets
